# Approved design direction — Proof, not pitch

Approved 2026-08-11.

- Palette: Nex Ink, Clean Canvas, Scan Mist, Action Blue, Marker Yellow, Fault Red.
- Type: Syne 700 for restrained display use; IBM Plex Sans 400/500/600 for body, data, and controls.
- Visual grammar: the NEX → FORM reform seam separates the current state from a stronger outcome.
- Signature: a working Website Check rail in the hero, covering speed, mobile, findability, and conversion.
- Layout: diagnostic hero, proof ledger, two-bad-options comparison, asymmetric offer ladder, evidence wall, conversion loop, market-language section, final Website Check.
- Ambient motion: one hero background field drifts by no more than 40px.
- All animation timings, easing, once-only behavior, reduced-motion fallback, navigation behavior, hover behavior, and transitions follow the approved Phase 1 specification verbatim.
